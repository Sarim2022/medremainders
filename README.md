# 💊 MedReminders

**College Minor Project – Semester 6**

A smart medicatio  developed using Flutter and Firebase, integrated with AI to help users manage their health effectively.

---

## 🚀 Project Overview

MedReminders is a mobile application that allows users to:
- Authenticate and manage secure accounts
- Set up medication reminders
- Generate personalized schedules using a machine learning model
- Ensure seamless data sync with Firebase

---

## 🛠️ Built With

- **Flutter** – Frontend Framework  
- **Dart** – Programming Language  
- **Firebase** – Authentication & Database  (R)
- **Cursor.ai** – AI Integration  
- **VS Code** – IDE  
- **GitHub Pages + Jekyll** – Hosting  
- **WebIntoApp** – Web to APK conversion
